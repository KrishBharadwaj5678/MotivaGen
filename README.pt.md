## <img src="https://github.com/KrishBharadwaj5678/MotivaGen/raw/main/assets/readme/gettingStarted.gif" width="35"/> Como Começar

### 1️⃣ Clonar o Repositório

```bash
git clone https://github.com/KrishBharadwaj5678/MotivaGen.git
```

### 2️⃣ Acessar o Diretório do Projeto

```bash
cd MotivaGen
```

### 3️⃣ Instalar as Dependências

```bash
pip install -r requirements.txt
```

### 4️⃣ Executar o Aplicativo

```bash
streamlit run app.py
```
