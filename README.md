# 🚀 MotivaGen

Experience the thrill of endless inspiration and elevate your mood with just a click.
Start creating your daily dose of motivation with **MotivaGen**, your personal motivation generator.

![MotivaGenDemo](https://github.com/KrishBharadwaj5678/MotivaGen/blob/main/MotivaGenDemo.png)

## ✨ Features

| Feature                        | Description                                         |
| ------------------------------ | --------------------------------------------------- |
| 💡 Random Motivation Generator | Get instant motivational quotes and inspiration     |
| ⚡ One Click Interaction        | Simply click to generate a new motivational message |
| 😊 Mood Booster                | Helps improve mindset and daily positivity          |
| 🎨 Clean UI                    | Minimal and user-friendly Streamlit interface       |
| 🌐 Web-Based                   | Accessible from any browser without installation    |
| 📱 Responsive Design           | Smooth experience across devices                    |

## 🚀 Getting Started

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/KrishBharadwaj5678/MotivaGen.git
```

### 2️⃣ Navigate to the Project

```bash
cd MotivaGen
```

### 3️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

### 4️⃣ Run the App

```bash
streamlit run app.py
```
