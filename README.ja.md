<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/MotivaGen/raw/main/assets/icons/icon.png" width="35"/> MotivaGen</h1>

<p align="center">
  MotivaGenは、集中力を維持し、困難を乗り越え、目標に向かって意味のある一歩を踏み出せるよう、パーソナライズされたモチベーションを提供します。
</p>

## <img src="https://github.com/KrishBharadwaj5678/MotivaGen/raw/main/assets/readme/features.gif" width="35"/> 主な機能

| 機能               | 説明                            |
| ---------------- | ----------------------------- |
| 💡 ランダムモチベーション生成 | モチベーションを高める名言やインスピレーションを即座に取得 |
| ⚡ ワンクリック操作       | クリックするだけで新しいモチベーションメッセージを生成   |
| 😊 気分をリフレッシュ     | 前向きな気持ちや日々のモチベーションをサポート       |
| 🎨 シンプルなUI       | ミニマルで使いやすいStreamlitインターフェース   |
| 🌐 Webベース        | インストール不要で、ブラウザから利用可能          |
| 📱 レスポンシブデザイン    | さまざまなデバイスで快適に利用可能             |

## <img src="https://github.com/KrishBharadwaj5678/MotivaGen/raw/main/assets/readme/gettingStarted.gif" width="35"/> はじめに

### 1️⃣ リポジトリをクローン

```bash
git clone https://github.com/KrishBharadwaj5678/MotivaGen.git
```

### 2️⃣ プロジェクトディレクトリへ移動

```bash
cd MotivaGen
```

### 3️⃣ 依存関係をインストール

```bash
pip install -r requirements.txt
```

### 4️⃣ アプリを起動

```bash
streamlit run app.py
```
